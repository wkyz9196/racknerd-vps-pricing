## FAQ

**8GB 内存够跑什么？**
MySQL 或 PostgreSQL 在几十 GB 数据量下能保持热数据在内存里；Docker 跑五到十个轻量容器没问题；Ollama 这类本地模型推理工具官方标注 4GB 起，OpenClaw 标注 8GB 起，8GB 特价正好压在这条线上。跑 32B 以上的模型或大规模训练不够。

**8GB 配 150GB 硬盘够不够？**
比多数同价位方案宽裕。Aquatis 的 8GB 只配 20GB NVMe，HostHatch 的 8GB 只配 35GB NVMe，RackNerd 给 150GB SSD。如果主要跑数据库和容器，150GB 够用很久；如果存视频或做镜像仓库，还是要单独规划存储。

**国内访问选哪个机房？**
洛杉矶 DC03 和西雅图是常规选择，洛杉矶还支持免费 IPv6。达拉斯位置居中，到东西海岸延迟均衡。纽约适合面向北美东部的业务。VPS 的实际回国线路会随运营商和时间段波动，没有“保证低延迟”的选项。

**年付一定比月付划算吗？**
算下来划算，但前提是确定用满一年。常规线 KVM-8GB 年付比月付省 12.2%，Aquatis 8GB 年付只省 6%。如果只是短期测试或需求可能变化，月付多花的钱买的是灵活度。RackNerd 特价线没有月付版本。

**RackNerd 适合跑数据库吗？**
能跑，但别按生产级数据库的预期来。共享 KVM 的 IOPS 没有公开承诺，没有托管数据库服务，备份要自己做。个人项目、开发环境、小流量站点可以；对 SLA 和 IOPS 有硬性要求，应该看独立服务器或云数据库。

**16GB 内存的 VPS 有吗？**
Linux KVM 线公开最高到 KVM-12GB（$565.59/年）。16GB 只出现在 Windows VPS 产品线，6 核、200GB NVMe、10TB 流量、$89.59/月，含 Windows 授权。想要 16GB 的 Linux 机器，这个价位不如考虑两台 8GB 特价分担负载。
